# résumuncher

A maze game where every dot is a word of my resume. Eat the dots, avoid the bugs, and the resume assembles itself.

**Play it at [dhansomaiah.github.io](https://dhansomaiah.github.io).** Arrow keys or WASD on a computer, swipe on a phone.

One `index.html`, no dependencies, no build step.
